# MIDI 控制器（Bome MIDI Translator 替代，第一版框架）

把 MIDI 键盘（如 MVAVE SMK25）当作电脑控制器：MIDI 输入 -> 规则匹配 -> 动作。

## 运行

打包版：双击 `dist\MIDIController\MIDIController.exe`，无需安装 Python。
移动或分享时请携带整个 `MIDIController` 文件夹（包括 `_internal`），不要只复制 EXE。
配置保存在 EXE 同目录的 `config.json`；首次打包带入已有映射，重新打包不覆盖已有打包版配置。
请放在有写入权限的普通文件夹中。
最小化或关闭窗口可收进系统托盘，单击或双击托盘图标恢复；右键可暂停映射或退出。
重新构建：安装 PyInstaller 后运行 `build.ps1`。

```powershell
.\run.ps1          # 普通启动（无控制台）
.\run.ps1 -Admin   # 管理员启动（控制管理员权限程序时需要）
.\run.ps1 -Test    # 离线自检（跑 tests/ 下的 24 个单测）
python main.py     # 带控制台启动，便于看报错
```

依赖：Python 3.12 + `requirements.txt`（PySide6、mido、python-rtmidi、pycaw、comtypes、psutil、qtawesome）。安装：`pip install -r requirements.txt`。打包另需 `pip install -r requirements-build.txt`。仅支持 Windows。

## 使用

1. 顶栏选择 MIDI 输入端口（键盘接上后点刷新）。
2. 选中左侧配置，点“新建映射”，在对话框里点“学习”，再按一下键盘上的琴键、旋钮或打击垫。
3. 选择动作并保存。底部监视器会实时显示收到的 MIDI 消息。
4. 新建配置并绑定进程名（如 `chrome.exe`），前台切到该程序时自动启用；未命中的映射回落到“全局”。
5. 关闭窗口会最小化到托盘，从托盘菜单退出。

## 规则

- 触发：Note / CC / 弯音轮 / Program；通道、编号可设为“任意”；事件为按下、松开、按下+松开、数值变化、增大/右转、减小/左转。CC 选“按下/松开”时以 64 为阈值。
- 数值范围：只在输入数值落在范围内时触发（如推子 100-127）。
- 旋钮编码：绝对值（SMK25 默认）或两种常见相对编码，用于方向判断。
- 手势：普通（立即）、短按、长按（阈值可调）、双击（300ms 内）。同一个键可同时配置三种手势。
- 条件：`shift==1, mode!=2, $value>64`，逗号分隔，全部满足才触发。配合“设置变量”动作做 Shift 层、模式切换。
- 停止后续：命中后不再处理同一配置里排在后面的映射，用于层覆盖。
- 动作列表：一个触发依次执行多个动作，每个动作可设延迟（宏）。
- 动作：按键组合（点按、跟随按住、仅按下、仅松开）、按住连发、鼠标按键/移动/滚轮、媒体键、系统音量、启动程序、打开网址、运行命令、发送 MIDI、设置变量、切换配置。
- TourBox 式旋钮动作：
  - 鼠标滚轮：可带修饰键（如 `ctrl` 缩放）、跟随旋钮方向、加速。
  - 修饰键+拖动：旋钮转动时按住修饰键和鼠标键并移动，停止后自动松开（如 PS 的 `alt`+右键拖动调笔刷）。
  - 旋钮步进按键：右转/左转各发一个按键（如 `]` / `[`），可加速。
  - 加速：转得越快，每格步数越多（最多 8 倍）。
- 屏幕提示：映射勾选后，触发时在鼠标旁显示名称、数值和变量。
- 配置保存在 `config.json`。

### 示例：Shift 层

1. 映射 A：打击垫 1，事件“按下+松开”，动作“设置变量 shift 设为输入数值”（按下时为力度，松开时为 0）。
2. 映射 B：琴键 C4，条件 `shift>0`，勾选“停止后续”，动作 `ctrl+z`。
3. 映射 C：琴键 C4，无条件，动作 `z`。

## 结构

| 文件 | 作用 |
|---|---|
| `midictl/midi_io.py` | 端口、消息标准化、触发匹配 |
| `midictl/engine.py` | 事件队列线程、按前台程序选配置 |
| `midictl/rules.py` | 变量与条件 |
| `midictl/actions.py` | 动作执行 |
| `midictl/win_input.py` | Windows SendInput（扫描码键盘、鼠标） |
| `midictl/ui_main.py`, `ui_mapping.py` | 主窗口、映射编辑对话框 |
